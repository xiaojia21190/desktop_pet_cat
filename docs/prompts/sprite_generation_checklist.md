# Sprite 生成验收清单（单动作单图）

## 基础规格

- 每张图为 `1x8` 网格，单格 `170x139`。
- 透明背景；未使用帧必须全透明。
- 猫咪始终朝右（不允许镜头方向漂移）。
- 同一猫咪各动作体型比例一致（头身比、腿长、尾巴粗细不突变）。

## 动画可读性

- 关键帧明显：起势、峰值、回收。
- 循环动作首尾可闭环（尤其 `walk/trot/run/tail_wag`）。
- 非循环动作终帧落在稳定姿态（避免卡住跳变）。

## 风格一致性

- 线条粗细一致、阴影方向一致。
- 色板不跳变（同一猫咪不同动作保持同色相与明度层级）。
- 不出现额外道具、水印、文本。

## 导入前检查

- 文件名遵循 `{cat_id}_{action_key}.png`。
- `sprite_manifest.json` 中存在对应条目。
- `frames/speed/loop` 与动作设计一致。

## 回归检查

- 进入项目后，动作切换不报错。
- 缺帧动作不会越界采样。
- `headless` 启动与自动化测试不过回归。
